# Skills

| Skill | What it does |
|-------|--------------|
| [launch-video](launch-video/SKILL.md) | Turn a one-line prompt into a finished, on-brand launch video through a phased agent workflow (brand-frame → storyboard → audio → visuals → render → ship). |
| [mini-socials-quote-card](mini-socials-quote-card/SKILL.md) | Turn a 名人訪談 YouTube link into a 4:5 「金句 card」: a sharp interview frame with the quote stacked as dark caption bars, one line each, in 繁中 (the 花卷 look). |
| [publish-skill](publish-skill/SKILL.md) | Publish a skill to a public GitHub `skills` mono-repo in the skills.sh layout, installable via `npx skills add`. |

New skills go here as `skills/<name>/SKILL.md`.
